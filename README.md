# VanHuy-NewEra---YT-DLP
TOOL TẢI VIDEO TỪ MXH | BY VANHUY

Một công cụ Python sử dụng yt-dlp để tải Video, MP3 và Phụ đề từ nhiều nền tảng mạng xã hội.

Tính năng

- Tải Video MP4 chất lượng cao.
- Tải Âm thanh MP3 (320kbps).
- Tải phụ đề SRT (nếu nền tảng hỗ trợ).
- Hiển thị thông tin video trước khi tải.
- Thanh tiến trình tải trực quan.
- Tự động cập nhật yt-dlp.
- Hỗ trợ nhiều nền tảng.

Nền tảng được hỗ trợ

- YouTube
- TikTok
- Bilibili
- Facebook Video
- X (Twitter)
- NicoNico

Yêu cầu

- Python 3.10 trở lên
- FFmpeg
- yt-dlp

Cài đặt

Clone repository:

git clone https://github.com/Caovanhuy1777/VanHuy-NewEra---YT-DLP.git

cd Downloader

Cài đặt thư viện:

pip install -r requirements.txt

Khởi chạy:

python download.py
